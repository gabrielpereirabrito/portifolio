# 🎮 Meu Portfólio Dev

Bem-vindo ao meu espaço na web! Este é o meu portfólio e site pessoal, um projeto construído não apenas para mostrar os trabalhos que já realizei, mas também para captar de forma técnica a minha essência, habilidades e as coisas pelas quais sou apaixonado.

A identidade visual que escolhi é uma mistura de temas que eu adoro: **RPG de mesa, estilo Cyberpunk e a nostalgia de Pokémon**. Tudo isso é recheado com microinterações divertidas e alguns _easter eggs_ escondidos por aí (será que você consegue encontrar o terminal falso ou o Konami Code?).

## 🛠️ Como foi construído?

Para dar vida a essa ideia, tomei algumas decisões técnicas com o objetivo de ter um site rápido, imersivo e fluido. Sem usar muitos jargões complicados, aqui estão as principais ferramentas que utilizei:

- **React e Vite**: A base principal do site. O React me ajuda a organizar tudo em pequenos blocos (componentes), e o Vite torna o processo de criação e carregamento incrivelmente rápido.
- **TypeScript**: Adiciona uma camada extra de segurança ao código. É como ter um assistente que me avisa se eu esquecer algo importante, facilitando muito a manutenção.
- **Tailwind CSS**: A ferramenta de design que usei para estilizar tudo rapidamente. É com ele que crio aqueles contrastes marcantes do tema cyberpunk e os detalhes em neon brilhante.
- **GSAP**: A verdadeira mágica por trás das animações! Uso o GSAP para criar sequências fluidas, efeitos de transição complexos e detalhes interessantes quando você rola a página ou passa o mouse por cima dos itens.
- **Phosphor Icons**: Uma coleção de ícones para manter a interface consistente. Também misturei com algumas imagens personalizadas para dar vida aos "itens mágicos" do RPG.
- **Tipografia Temática**: Escolhi fontes que combinam com o universo do site, como a _Orbitron_ para dar um ar futurista aos títulos e a _JetBrains Mono_ para as partes com carinha de código e terminal.
- **Cloudinary**: onde ficam hospedadas as imagens do site. Além de guardar os arquivos, ele entrega cada imagem já no tamanho e no formato ideais para o seu aparelho — então mesmo com bastante arte na tela, o carregamento continua leve, inclusive no celular.

## 🧩 Fichas de Personagem

Em vez de apenas listar projetos de forma tradicional, cada trabalho meu é apresentado como uma "Ficha de Personagem". Lá você encontra o grau de dificuldade (de 1 a 5 estrelas) e os "status", que são as tecnologias que usei em cada aventura.

## 🚀 O que vem por aí?

Este é um projeto vivo! Por enquanto o foco é trazer uma experiência visual marcante e rápida, mas a arquitetura já está preparada para crescer no futuro e, quem sabe, ganhar um painel de controle ou um blog próprio.

Fique à vontade para explorar o código, se inspirar e acompanhar as atualizações!
